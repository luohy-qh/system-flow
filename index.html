模型说明

L1 准静态仿真，步长 1 s。纵向动力学取整车页公式；电堆性能由稳态页公式在「电流密度 × 温度」上扫描成 MAP，极化曲线以稳态页输入的节电压为锚点自校准（保证仿真起点与稳态结果零漂移）；电池为 Rint 等效电路 + DC/DC 效率 + SOC 库仑积分（欧姆损耗按 I²R = R·(P/V)² 计入）；冷却回路为一阶集总热容，冷端取仿真页「环境温度」，三通阀由 PI 闭环、低温段由 PTC 补热；膜含水量 λ 由电堆干侧 / 湿侧与阴极出口中最湿润的 RH 再叠加阴极出口液态水推算。工况结束后的 60 s 为停机观察段（车辆已停，仅保留附件负载）。
注意：内置 NEDC / WLTC / CLTC 曲线为轮廓近似，仅供趋势参考，不代表标准工况逐秒真值；全部参数在点击「开始仿真」时一次性快照，运行中修改稳态页参数不会影响本次结果。

整车工况仿真 · 使用说明

纯前端单文件，无需安装、无需联网、无外部依赖，双击 HTML 即可运行。

一、它在整个工具里的位置

三个页面是一条从「部件设计」到「整车表现」的链路，参数自上而下传递：

页面作用输出
① 燃料电池系统设计稳态设计点：电堆、氢气、空气、换热、COG 加湿器电堆功率、氢耗、节电压、产热、各支路流量
② 混合动力系统匹配整车匹配：动力性（最高车速 / 爬坡 / 加速）、储氢量、电池需求所需电堆功率、百公里氢耗、单瓶储氢质量、所需瓶数
③ 整车工况仿真时域仿真：把①②的设计点放进真实行驶工况里跑，看动态表现时刻曲线、多策略对比、能耗 / 温度 / SOC / 水管理指标

关键设计：第三页不重复任何公式。它把①②页的稳态公式当作「性能查表引擎」——在「电流密度 × 冷却液温度」网格上扫描出电堆 MAP，再用一张极化曲线把 MAP 平滑成连续曲面。因此改①②页的参数，第三页的仿真结果会跟着变。

二、快速上手（5 步）

  1. 打开 system-flow.html，确认 ①② 页参数是你要的设计点（默认值即可直接跑）。
  2. 切到「整车工况仿真」Tab。
  3. 左侧「▎ 控制策略」勾选你要对比的策略（默认 4 种全选，可对比也可只留一种）。
  4. 点 开始仿真。进度条和 t = ... / 1860 s 会实时推进，默认 20 倍速，约 3 秒跑完。
  5. 看结果：上方 KPI 卡片 → 中间 8 张曲线图 → 下方「策略对比汇总」表。
  6. （可选）点 导出结果(CSV) 把逐秒数据存下来做后续分析。
第一次点「开始仿真」前，图表区是空的——这是正常的，图表在运行后才绘制。

三、按钮说明

按钮行为
开始仿真参数快照 → 生成工况 → 标定极化曲线 → 从 t=0 开始跑。已跑完时点它 = 重新开始
暂停冻结推进，保留已有结果；再点一次继续（或点「开始仿真」继续）
停止结束推进并按已跑到的时刻结算汇总表（不跑完也能看部分结果）
重置清空结果、清空图表、回到「未运行」状态
导出参数把本页全部参数存成 JSON（弹出系统「另存为」，可自选文件夹）
导入参数读取 JSON 覆盖本页参数，并自动重置仿真
导出结果(CSV)导出逐秒结果 + 汇总表；文件名带时间戳，首行带 BOM（Excel 直接打开不乱码）

4.1 ▎ 行驶工况

仿真时长(s)1800仅「等速巡航」生效；其它预设工况的时长由曲线自身决定
巡航车速(km/h)60仅「等速巡航」生效

附加载荷(kg)0叠加在整车页整备质量上（货重 / 乘员）
附加电负载(kW)0叠加在整车页附件功率上（空调 / 上装设备）

自定义折线是最实用的入口：把实测逐秒车速（如从 GPX / 车联网数据导出的）直接粘进来，用「秒,车速」两列即可，内部会自动线性插值到每秒一点并算出加速度。

内置的 NEDC / WLTC / CLTC 是轮廓近似（用匀速段 + 匀加速段拼出的形状），只用于观察趋势差异，不能当作标准工况的逐秒权威数据，也不要用它去报法规油耗。
4.2 ▎ 电堆与极化曲线

电堆性能用一个三参数极化模型描述，再用①②页的稳态结果把第三条参数「反解」出来：

V(j, T, λ) = OCV − b·ln((j + j₀)/j₀) − R_cal·j + dVdT·(T − T_ref) + k_λ·(λ − λ_ref)
参数默认说明
开路电压 OCV(V)0.95单节可逆电压
Tafel 系数 b(V)0.035活化极化斜率，越大越「软」
参考电流密度 j₀(A/cm²)0.02活化极化起点
电压温度系数(V/K)−0.002见 §8「已知近似」，建议按实测标定
湿度电压灵敏度(V/λ)0.006膜越干电压越低
最小净功率(kW)6电堆怠速下限
额定净功率(kW)72「恒功率型」策略的目标值
最大净功率(kW)80电堆净输出上限（已扣空压机、泵、风扇、氢循环泵等 BOP 实算功耗）
功率上升率(kW/s)5加载速率限制
功率下降率(kW/s)5降载速率限制

R_cal 不用你填：程序用①②页的「节电压」作锚点反解它，保证仿真的起点（t=0 的第一个工作点）与稳态页结果零漂移。这是整套模型可信度的地基。

参数默认说明

额定电压(V)350与内阻一起决定欧姆损耗
内阻(mΩ)60欧姆损耗按 P = R·(P_bus/V)² 计入

充放电可用功率会随 SOC 向两端线性收窄，这是「缺功率」和「弃电」两个指标的来源。

两条温度相关但作用不同：

  • 「环境温度」= 散热器的冷端，影响散热能力；
  • 「冷态参考温度 + 冷态最低功率系数」= 低温功率限制（低温下膜电阻大、水管理难，不许大电流）。

把「环境温度」调成 45℃ 就是高温工况，散热能力下降；调成 −10℃ 就是寒区工况。

4.6 ▎ 控制策略（可多选对比）
策略逻辑适合场景
恒功率规则型电堆恒定输出额定净功率，差额由电池吞吐最简单的基线，通常氢耗最差，用来「垫底」对比
功率跟随电堆尽量等于整车需求功率直白、电池吞吐小；冷启动时会被强制拉高功率暖机
最高效率点+SOC滞环电堆锁在最高效率点，用 SOC 上下限做双点滞环切换追求电堆自身效率最高，但两态跳变会让 SOC 波动大
效率优先+SOC维持前馈跟随需求 + 按 2.5·容量·(目标SOC − 实际SOC) 反馈修正综合表现通常最好，SOC 稳、氢耗低

所有策略都叠加两条硬约束：

  1. 暖机优先：冷却液低于（目标温度 − 5℃）时，命令功率不低于当前可用功率的 70%，优先产热快速升温；
  2. SOC 保护：SOC 触顶时压低电堆功率避免过充，触底时强制电堆出力。

六、重要机制：参数快照

点「开始仿真」的瞬间，程序会把①②③三页的全部相关参数一次性快照下来。此后：

  • 运行中修改①②页参数 → 不影响本次结果。要生效必须重新点「开始仿真」；
  • 运行中修改③页参数 → 同样只在下一次仿真生效（阈值带、目标线等显示类参数除外，它们实时跟随）；
  • ①②页的仿真结果面板（数据气泡、结果卡片）在仿真期间被冻结，不会被仿真内部计算干扰。

这样设计是为了保证一次仿真内部参数自洽——否则逐秒数据里混入中途变更的参数，结果无法解释。

七、推荐实验清单

按顺序做下来，能把这套模型的能力摸清：

  1. 策略基线：工况类型选「等速巡航」、30 km，4 策略全选 → 建立氢耗排序直觉。
  2. 载荷敏感性：附加载荷 0 / 2000 / 10000 kg → 看氢耗与温度峰值同步上升。
  3. 坡度边界：坡度 0 / 5 / 10% → 10% 坡大概率出现「缺功率」，理解动力边界。
  4. 冷启动对比：把「启动冷却液温度」设成 −30℃ vs 25℃（仿真段要够长——太短两档会一起饱和；预设工况时长由曲线自身决定，选「等速巡航」时请把仿真时长设到 1800 s）→ 看汇总表的「功率受限(s)」与「PTC补热(kWh)」两列明显抬升；「效率优先」策略则表现为氢耗变化不大但 SOC 终值明显下降——电堆被功率封顶后差额由电池补上，冷启动的代价记在电池头上。
  5. 电池容量敏感性：5 / 20 / 60 kWh → 容量越小，「弃电」越少但「缺功率」越容易发生。
  6. 工况形状对比：等速巡航 vs 近似 WLTC → 变工况的氢耗显著更高。
  7. 实测数据导入：用「自定义折线」粘贴真实逐秒车速，得到有工程意义的结论。

八、模型边界与已知近似（务必了解）

这套模型是 L1 准静态仿真，定位是「设计点趋势与策略对比」，不是高保真车辆仿真工具。

能信的部分

  • 能量守恒严格闭合（内部有自检：∫电堆净功 + ∫电池母线功 ≡ 需求 − 缺功率 + 弃电，误差恒为 0）
  • 仿真起点与①②页稳态结果零漂移（极化曲线锚点自校准）
  • SOC 库仑积分精确
  • 物理单调性正确（载荷↑ → 氢耗↑，坡道↑ → 缺功率↑）

需要留意的近似

近似影响
1 s 定步长、准静态不模拟电化学瞬态（双层电容、气体传输延迟），秒级以下动态不可信

弃电是模型产物真实控制器会通过降低电堆输出来避免浪费，「恒功率型」的大额弃电应理解为「该策略不合理」的信号，而非真实整车油耗
空压机与辅机功耗（①页）①页的「压缩级数」「带尾气膨胀机」与泵/风扇/氢循环泵参数会改变本页结果：仿真扣除的是BOP 总功耗 = 空压机净功耗（压缩功耗 − 膨胀机回收功）+ 冷却液泵 + 散热风扇 + 氢气循环泵，四项均在①页实算，不再是固定值。膨胀机按纯气相等熵膨胀计算，尾气含水时未计凝结潜热，也未计真实涡轮中凝结滞后造成的非平衡损失，回收功为气相估计值。阴极压损直接决定膨胀比 → 压损越小、回收越多

九、常见问题

Q：点了开始仿真，图是空的？
A：图表在运行后才绘制。确认进度条在动；若已停止，点「开始仿真」重跑。

Q：改了参数，结果没变？
A：参数快照机制（见 §6）。必须重新点「开始仿真」。显示类参数（λ 阈值带、温度目标线）会实时跟随。

Q：出现「缺功率」怎么办？
A：说明这套动力系统扛不住当前工况。按优先级调：加大「最大净功率」→ 降「附加载荷 / 坡度 / 巡航车速」→ 放宽「SOC 下限」→ 加大「最大放电功率」。

Q：温度峰值超过 100℃？
A：散热能力不足。加大「散热器面积」或「风扇风量系数」，或降低第一页的冷却液温度设定 / 提高「冷却回路热容」。

Q：温度一直上不去（冷启动很久）？
A：检查「PTC 最大功率」是否足够；「冷态最低功率系数」过小会导致低温下功率被限制、产热不足，形成「升不上去」的困局。

Q：「弃电」很大是不是算错了？
A：不是。它表示电池吸不完电堆富余功率。这正是「恒功率规则型」策略氢耗最差的原因，属于有效的策略评价结果。

Q：λ 越限时间很长？
A：先看 λ 曲线整体水平。若整体偏高 → 调高「水淹阈值」或降低第一页加湿器效率；整体偏低 → 调低「干膜阈值」。若只在冷启动段越界，属于正常现象。

Q：导出的 CSV 用 Excel 打开中文乱码？
A：文件已带 BOM，正常不会乱码。若仍异常，用 Excel「数据 → 从文本/CSV」导入并指定 UTF-8。

Q：能同时对比两个以上策略吗？
A：可以，4 种可任意组合多选。分析的策略数越多，单帧计算量线性增加，但默认 20× 倍速下仍足够流畅。

十、一句话总结

把①②页当作「设计点定义」，用③页回答三个问题：这套设计能不能跑完这个工况（缺功率 / 温度 / SOC）、跑下来要烧多少氢（百公里氢耗 / 系统效率）、哪种能量管理策略更好（多策略同工况对比）。超出这三个问题的判断（法规油耗申报、膜寿命预测、电化学瞬态），需要更高保真度的模型。
